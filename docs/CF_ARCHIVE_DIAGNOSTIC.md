# Authenticated read-only archived vote diagnostic

GET /v1/review-status?proposal_sha256=<64 lowercase hex> uses the existing review-client authentication. It reads the active enrolled key, cached public vote and nonce index. It returns an explicitly archived vote with diagnostic_read_only=true, current_authorization=false and archived_vote_expired, plus the key's persisted clock watermark. It never calls the signer, writes storage, burns a leaf or treats expiry as valid. Existing POST review freshness requirements remain unchanged. A missing cache is reported without creating it. Config, policy, key, proposal and nonce bindings must match. Only public proof and numeric commit metadata are disclosed; no private key state is returned.
